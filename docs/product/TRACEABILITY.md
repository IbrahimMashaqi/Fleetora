## Searchable operational selectors

UX-01 / BR-076 / FR-SH-09 / BR-043 — project-wide focus-retention follow-up (`feature/ux-combobox`, owner 2026-11-27): the initial browser regressions reproduced a typing-driven parcel-list navigation/focus loss and Server Action requests from record searches. `fe/components/ui/combobox.tsx` now keeps draft input text separate from its committed record value; typing, including clearing typed text, neither calls the parent's selection callback nor clears the committed ID. Selection/explicit clear commit the value; Arrow keys, Enter and Escape retain the same input element. `fe/features/operations/components/entity-combobox.tsx` keys state by identity/resource/field rather than search/selection props.

`fe/app/api/read/route.ts`, `fe/lib/api/read.route.ts`, `read-contract.ts` and `read.client.ts` provide same-origin, private/no-store fetch reads using the existing session, tenant and feature validators. Write/invitation/assignment/payment operations cannot be dispatched through this route. Cookie refresh remains serialized; authentication rejection invalidates the local protected session so stale private records are removed. Typing-triggered price previews and duplicate-phone checks, and the background driver-access read, use this transport too. `fe/lib/use-debounced-search.ts` updates directory results in place; parcel/merchant/driver/vehicle/warehouse/account searches no longer navigate while typing. Explicit links, pagination, record-save navigation and filter submission retain their existing behavior.

The audit and Flutter-only inventory are recorded under UX-01 in `DECISIONS.md`; the permanent technical rule is appended to `fe/AGENTS.md`. Available-vehicle assignment and manufacturer/model selectors now use the shared Combobox with authenticated, Arabic-aware backend searches. `be/parcels/lookup.repository.ts`, `lookup.dto.ts` and `lookup.http.spec.ts` retain fleet permissions and unassigned-only vehicle eligibility, company isolation and 10/20 result limits. This supersedes the previous entry's local vehicle-catalogue filtering. Short status/action/role enums and free-form creation/contact fields remain distinct from record pickers. No Flutter or schema/migration files are changed.

Coverage: `fe/tests/focus-retention.ts` types `مح` character by character and checks text, focus, original DOM-node identity, unchanged URL and absence of Server Action requests. Browser regressions cover directory searches, the operations dashboard, filters, parcel create/edit/assignment/warehouse receipt, pickup drivers, collection parcels, pricing merchant/plan/zone selectors, and vehicle assignment/brand/model selectors. `fe/tests/harness/combobox.browser.spec.ts` also verifies a draft does not change the hidden committed ID until selection/clear. `fe/features/operations/read.action.spec.ts` covers same-origin enforcement, changed tenant scope and rejection of writes; the existing action/session/permission tests and disposable-PostgreSQL vehicle normalization/eligibility/cross-company regressions remain in force.

All 131 affected action/read-route tests, 18 backend normalization/HTTP permission/catalogue tests and 35 disposable-PostgreSQL integration tests passed. ## Identity / RBAC

Tokens remain in fragments/client memory and request bodies, never queries or Server Action arguments.
